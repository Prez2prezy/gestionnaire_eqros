LES ÉQUIPES DU ROSAIRE — DIOCÈSE DE GRAND-BASSAM
👁️ Tu regardes cette page depuis une autre application (WhatsApp, Instagram…). Touche d'abord ⋮ → « Ouvrir dans le navigateur » (ou ⋯ en haut), puis pose le raccourci ici — le geste n'existe que dans le navigateur.
Le téléphone connaît le geste : touche, accepte, c'est posé — plein écran, au bon visage.
  1. Touchez le menu ⋮ du navigateur (ou Partager sur iPhone).
  2. Choisissez « Ajouter à l'écran d'accueil » — le raccourci prend son vrai visage : Rosaire et son chapelet doré.
  3. Validez — c'est tout : à chaque ouverture, vous arrivez directement dans l'Espace de Prière.
